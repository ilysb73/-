# 사라진 인천을 찾아서 — 부평·계양 문화유산 탐정단

초등 4학년 인천형 세계시민교육 비주얼 노벨 · 읽걷쓰 AI · 약 15분

부평과 계양의 문화유산이 **도시개발과 무관심**으로 사라져 가는 현장을, 읽걷쓰 AI 리리와 친구 민준이와 함께 **탐정**이 되어 조사해요.
마지막 메시지: **“우리 동네의 기억을 지키는 것, 그것이 인천에서 읽걷쓰 AI로 자라는 세계시민의 첫걸음!”**

- **빌드가 필요 없는 웹 게임**(HTML·CSS·JavaScript)이라 GitHub에 올리기만 하면 바로 링크로 실행돼요.
- 컴퓨터·태블릿·휴대폰(가로) 모두 가능, 글자는 화면 크기에 맞춰 커지고 작아져요.
- 진행 상황이 자동 저장돼서 창을 닫아도 **이어 하기**가 돼요.

## GitHub에 올려서 링크 만들기 (약 5분)

1. github.com 로그인 → 오른쪽 위 **+ → New repository**
   - 이름: 예) `incheon-heritage` · **Public** 선택 → **Create repository**
2. **uploading an existing file** 클릭
3. 압축을 푼 폴더 **안의 내용물 전부**를 끌어다 놓기
   (`index.html`, `style.css`, `game.js`, `story.js`, `README.md`, `assets` 폴더)
   → 아래 **Commit changes**
4. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, 폴더 **/(root)** → **Save**
5. 1~2분 뒤 Pages 화면 위쪽에 나오는 주소가 게임 링크예요.
   `https://아이디.github.io/incheon-heritage/` → QR코드로 만들어 나눠 주세요.

> 올린 뒤 링크가 404라면 1~2분 기다렸다가 새로고침하세요. `index.html`이 저장소 **맨 바깥(루트)** 에 있어야 해요.
