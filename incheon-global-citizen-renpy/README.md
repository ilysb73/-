# 리리와 함께하는 인천 세계시민 탐험 (Ren'Py)

인천형 세계시민교육(읽걷쓰 4P) × 읽걷쓰 AI × 금융교육 비주얼 노벨 · 초등학생 1인칭 · 약 10분

- 엔진: **Ren'Py 8.3** (웹 버전은 GitHub가 자동으로 빌드해서 GitHub Pages로 배포)
- **본미션 8개**(제한시간 20초, 4지선다 함정 보기) · **넌센스 퀴즈 4개**(10초) · **AI 리리와 대결 4판** · **스크래치 복권**
- 통과 기준: 193점 만점 중 **120점(62%)** → 설계상 통과율 절반 이하
- 해상도 1920×1080, 대사 46px · 선택지 38px 이상 (가장 작은 글자도 30px)

## 1. GitHub에 올려서 웹 주소 만들기 (처음 한 번, 약 10분)

1. **github.com** 로그인 → 오른쪽 위 **+ → New repository**
   - Repository name: `incheon-global-citizen` (원하는 영어 이름)
   - **Public** 선택 → **Create repository**
2. 새 저장소 화면에서 **uploading an existing file** 클릭
3. 압축을 푼 폴더 **안의 내용물 전부**(`game` 폴더, `.github` 폴더, `README.md`)를 끌어다 놓기 → **Commit changes**
   - ⚠️ `.github` 폴더는 숨김 폴더라 안 올라갈 수 있어요. 저장소에 `.github` 폴더가 없으면:
     **Add file → Create new file** → 이름 칸에 `.github/workflows/build-web.yml` 입력 →
     압축 파일 속 같은 이름 파일을 메모장으로 열어 내용을 그대로 붙여 넣기 → **Commit changes**
4. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꾸기
5. 저장소 위쪽 **Actions** 탭 → “Ren'Py 웹 빌드 & 배포”가 돌아가요 (3~6분).
   - 이미 끝났는데 Pages 설정 전이었다면: Actions → 해당 작업 → **Re-run all jobs**
6. 초록 체크 ✅ 가 뜨면 완료! 주소: `https://아이디.github.io/incheon-global-citizen/`
   → 이 주소를 QR코드로 만들어 부스에 붙이면 학생들이 바로 접속할 수 있어요.

> 처음 접속할 때 게임 파일(약 20~30MB)을 내려받느라 10~30초 걸릴 수 있어요. 부스 기기에서는 행사 전에 한 번 미리 열어 두세요.
> Actions 탭에서 빨간 ✖가 뜨면, 그 작업을 눌러 나온 오류 문구를 알려 주세요.

**분기:** 사샤와 친구가 되면 도서관에 다시 나와요 · 가짜 사진을 공유하면 도서관에서 결과를 알게 돼요 · 피싱 링크, 복권 구매, 예산 초과는 용돈에 바로 반영돼요.

## 3. 난이도 조절 (`game/data.rpy`, `game/minigames.rpy`)

| 바꿀 것 | 위치 | 지금 값 |
|---|---|---|
| 본미션 제한시간 | `MISSION_TIME` | 20초 |
| 넌센스 제한시간 | `QUIZ_TIME` | 10초 |
| 통과 기준 | `PASS_RATIO` | 0.62 (120점) |
| 함정 상자 수 | `MineGame(mines=4, need=3)` | 16칸 중 4개 |
| 슈팅 시간·목표 | `ShooterGame(duration=18.0, need=4)` | 18초, 4점 |
| 사목 수 제한·AI 실수 확률 | `OmokGame(max_moves=12, blunder=0.55)` | 12수, 55% |
| 복권 당첨 확률 | `SCRATCH_TABLE` | 일반 42%, 황금 70%, 가게 30% |

시뮬레이션(학생이 본미션 정답을 45% 고르고, 넌센스를 45% 맞힌다고 가정) 결과 통과율은 약 **34%**예요. 정답률이 55%인 학생 집단이면 약 54%가 통과해요.
행사 당일 실제 통과율은 메인 화면 **명예의 전당**에 “누적 참가 · 인증 통과 (%)”로 표시돼요.

## 4. 운영 팁

- **순위·통과율 기록**은 게임을 한 그 기기(브라우저)에 저장돼요. 엔딩 2쪽의 **순위 초기화(선생님용)** 로 지울 수 있어요.
- 되감기·저장 메뉴는 꺼 두었어요 (선택을 되돌려 점수를 바꾸지 못하게).
- 조작: 클릭/터치 · Space/Enter = 다음 · 숫자 1~4 = 선택지

## 5. PC에서 직접 실행·수정하고 싶다면 (선택)

1. https://www.renpy.org 에서 Ren'Py 8 SDK 내려받기
2. 이 폴더를 Ren'Py의 프로젝트 폴더에 넣고 런처에서 **Launch Project**
3. 런처의 **Web** / **Build Distributions** 로 웹·PC용 파일도 만들 수 있어요.
